# Prompt Pembuka Sesi AI

Salin prompt berikut untuk memulai sesi baru:

```text
Kamu mengerjakan repository SMANU SmartNutrition. Baca berurutan:
- AGENTS.md
- .project-ai/README.md
- .project-ai/AGENT.md
- .project-ai/PROJECT_CONTEXT.md
- .project-ai/PROJECT_STATUS.md
- .project-ai/project-management/NEXT_TASK.md
- .project-ai/history/SESSION_HANDOFF.md

Baca dokumentasi arsitektur dan modul yang sesuai. Periksa source code, Git status,
diff, serta perubahan pengguna sebelum mengedit. Kerjakan task pengguna terbaru;
jika tidak ada, gunakan NEXT_TASK.md tanpa mengganti isinya. Pertahankan fitur yang
sudah berfungsi, jangan mengarang konfigurasi atau hasil, dan jangan mengekspos secret.
Jangan mengubah database production, commit, push, atau deploy tanpa izin.

Setelah bekerja, jalankan pemeriksaan relevan, laporkan hasil secara tepat,
perbarui dokumentasi dan SESSION_HANDOFF.md. Catat perubahan yang belum di-commit
sebagai UNCOMMITTED WORK. Jangan menghapus atau menimpa perubahan pengguna.
```
