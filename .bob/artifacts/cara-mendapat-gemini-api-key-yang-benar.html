Cara Mendapat Gemini API Key yang Benar

Untuk SMANU AI Assistant di project "ibm company project"

⚠ Masalah yang Ditemukan dari Diagnostic

API key yang sekarang ada di .env.local adalah OAuth2 access token, bukan Gemini API key. Keduanya dari Google, tapi berbeda fungsinya.

❌ Yang ada sekarang (salah) Format: AQ.Ab8R...
Panjang: 53 karakter
Jenis: OAuth2 token

Tidak bisa digunakan untuk Gemini API
✅ Yang dibutuhkan (benar) Format: AIzaSy...
Panjang: 39 karakter
Jenis: API key

Ini yang berfungsi untuk Gemini API
1
Buka halaman API Keys Google AI Studio
Langsung ke halaman yang benar — bukan halaman lain

Buka browser dan masuk ke URL ini persis:

https://aistudio.google.com/app/apikey

Login dengan akun Google yang sama dengan project "ibm company project".

2
Pastikan kamu di halaman "API keys" yang benar
Halaman ini menampilkan daftar API key, bukan OAuth credentials

Halaman yang benar judulnya adalah "API keys" dan menampilkan tombol seperti ini:

Google AI Studio — API keys
+ Create API key
Get API key in new project
⚠ Kalau kamu melihat halaman "OAuth 2.0 Client IDs" atau "Service Accounts", itu halaman yang salah. Itu ada di Google Cloud Console, bukan Google AI Studio.
3
Cari API key yang sudah ada atau buat baru
Gunakan project "ibm company project" yang sudah ada

Jika sudah ada key di daftar: Lihat apakah nilainya dimulai dengan AIzaSy. Kalau ya, kamu bisa copy dari sana.

Jika perlu buat baru: Klik + Create API key → pilih project "ibm company project" → klik Create API key in existing project.

Contoh tampilan key yang benar
SMANU Project Key AIzaSy••••••••••••••••••••••••••••••
Key yang salah (jangan gunakan ini) AQ.Ab8R••••••••••••••••••••••••••••••
✅ Key yang valid SELALU dimulai dengan AIzaSy dan panjangnya sekitar 39 karakter.
4
Copy key dan update .env.local
Ganti baris GEMINI_API_KEY di file .env.local

Buka file nutripath/.env.local dan ganti baris ini:

# Baris lama yang salah:
GEMINI_API_KEY=AQ.Ab8RN6Jdz3QtP...

# Ganti menjadi (isi dengan key kamu):
GEMINI_API_KEY=AIzaSy_PASTE_KEY_KAMU_DISINI
⚠ JANGAN tambahkan spasi, tanda kutip, atau karakter lain di sekitar key. Langsung paste nilainya saja.
5
Restart dev server dan test
Wajib restart agar .env.local terbaca ulang

Di terminal proyek kamu:

# Stop server dulu (Ctrl+C), lalu:
cd nutripath
npm run dev

Setelah server berjalan, test langsung dari terminal (terminal baru):

# Test SMANU AI Assistant (Gemini):
curl -X POST http://localhost:3000/api/ai-chat \
  -H "Content-Type: application/json" \
  -d "{\"message\": \"halo, apa makanan bergizi?\"}"

# Expected: { "reply": "..." }
# Error jika key salah: { "error": "AI Assistant belum tersedia..." }
6
Update GEMINI_API_KEY di Vercel
Setelah local berhasil, update production

Buka vercel.com → Project SMANU → Settings → Environment Variables

Cari GEMINI_API_KEY → klik Edit → paste key baru yang dimulai AIzaSy... → Save → Redeploy.

✅ Tidak perlu mengubah LANGFLOW_* variables di Vercel.

✅ Ringkasan yang perlu dilakukan

  1. Buka aistudio.google.com/app/apikey
  2. Buat atau salin API key yang dimulai AIzaSy...
  3. Ganti GEMINI_API_KEY di .env.local
  4. Restart npm run dev
  5. Test dengan curl atau langsung buka SMANU AI Assistant di browser
  6. Kalau local berhasil → update key di Vercel → Redeploy
