BAGIAN A Export flow dari Langflow Desktop (laptop kamu)
1
Buka Langflow Desktop di laptop
Buka aplikasinya seperti biasa

Buka IBM Langflow Desktop di laptop — pastikan sudah muncul daftar flow kamu.

2
Arahkan kursor ke card flow SMANU
Jangan klik untuk membuka — cukup hover

👆 Klik tombol ⋮ (tiga titik) di pojok kanan card flow "SMANU Smart Nutrition for Student"
3
Klik Export dari menu dropdown
File .json akan otomatis ter-download
Menu yang muncul setelah klik ⋮
Rename Duplicate ⬇ Export Delete
👆 Klik Export — browser/sistem akan mendownload file SMANU Smart Nutrition for Student.json ke folder Downloads kamu
💡 Kalau tidak ada menu ⋮ di card, coba buka flow-nya dulu, lalu cari tombol Export di toolbar atas flow (biasanya icon ↓ atau ⋮ di kanan atas).
BAGIAN B Import file .json ke Langflow Cloud
4
Kembali ke halaman utama Langflow Cloud
Klik "Back to portal" di pojok kiri atas

Di browser, kamu sedang di halaman My Account. Klik "← Back to portal" di pojok kiri atas untuk kembali ke dashboard flow.

📍 Setelah klik, kamu akan melihat halaman daftar flow (mungkin masih kosong — itu normal)
5
Klik tombol untuk membuat/import flow baru
Cari tombol + New Flow atau Import

No flows yet. Create your first flow to get started.
👆 Klik "+ New Flow" lalu cari opsi "Import from file" atau langsung klik tombol "Upload" / "Import" jika ada
6
Upload file .json yang tadi di-download
Pilih file dari folder Downloads

or

👆 Klik Browse Files → pergi ke folder Downloads → pilih file SMANU Smart Nutrition for Student.json
✅ Flow akan muncul di dashboard Cloud setelah upload berhasil
BAGIAN C Ambil URL, Flow ID, dan buat API Key
7
Buka flow yang baru di-import → catat Flow ID dari URL
Lihat address bar browser kamu

Klik flow SMANU yang baru muncul untuk membukanya. Lihat address bar browser:

https://langflow.datastax.com/flow/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
📋 Bagian xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx itu adalah LANGFLOW_FLOW_ID baru kamu. Copy dan simpan.
8
Buat API Key baru di Langflow Cloud
Beda dari API key Desktop — harus buat baru

Di Langflow Cloud, klik foto profil / menu akun → Settings → API Keys → + Create new secret key

  • Beri nama: SMANU Vercel
  • Klik Create secret key
  • Copy API key yang muncul (sk-xxx...)
⚠ API key hanya ditampilkan sekali — langsung copy dan simpan di Notepad atau tempat aman sebelum tutup dialog!
9
Masukkan ke Vercel Environment Variables
3 variabel yang harus diisi

Buka vercel.com → Project SMANU → Settings → Environment Variables

Tambahkan/update 3 variabel ini:

LANGFLOW_SERVER_URL = https://api.langflow.astra.datastax.com
LANGFLOW_API_KEY = sk-xxx... (yang baru dibuat di Cloud)
LANGFLOW_FLOW_ID = Flow ID dari URL langkah 7
💡 LANGFLOW_SERVER_URL selalu tetap https://api.langflow.astra.datastax.com — tidak perlu diubah.
10
Redeploy di Vercel
Wajib agar env vars baru aktif

Vercel → Deployments → klik deployment terbaru → ⋮ → Redeploy

✅ Setelah redeploy selesai, coba kirim pesan di smanu-smart-nutrition.vercel.app/ask-smanu

✅ Checklist sebelum test

  • ☐ File .json sudah didownload dari Langflow Desktop
  • ☐ File .json sudah di-upload ke Langflow Cloud
  • ☐ Flow ID (dari URL Cloud) sudah dicopy
  • ☐ API Key baru dari Langflow Cloud sudah dibuat dan dicopy
  • ☐ 3 env vars sudah diisi di Vercel Settings
  • ☐ Redeploy di Vercel sudah dilakukan
