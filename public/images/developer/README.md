# Foto Developer

Taruh foto profil developer di folder ini.

## Nama file yang diharapkan
`developer-profile.jpg`

## Path yang digunakan di halaman About
`/images/developer/developer-profile.jpg`

## Format yang didukung
- `.jpg` / `.jpeg` (disarankan)
- `.png`
- `.webp`

## Ukuran yang disarankan
- Minimal: 200×200 px (persegi)
- Disarankan: 400×400 px atau lebih
- Ukuran file: < 200 KB

## Cara menggunakannya

Setelah file ditempatkan di sini, halaman About (`app/(main)/about/page.tsx`) akan
secara otomatis menampilkan foto jika ada. Jika file tidak ada, avatar placeholder
berisi inisial nama developer akan tetap ditampilkan.
